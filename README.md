A complete chess engine in one 4 KB Python file: a 0x88 board, move generation with castling, en passant and promotion, alpha-beta search with a transposition table, null-move pruning, late-move reductions, killer and history ordering and quiescence search, over a tapered material and piece-square evaluation with passed pawns, pawn shield and bishop pair. It plays the make.fun house gauntlet through the contest env.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
